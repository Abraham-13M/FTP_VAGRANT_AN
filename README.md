FTP con Vagrant y Ansible

El proyecto consiste en crear y configurar un entorno de servidores utilizando Vagrant y Ansible.
Hay que configurar tres maquinas virtuales, un servidor DNS, un servidor web y FTP seguro, y un nodo de control Ansible para automatizar la configuración.

Las herramientas que vamos a utilizar para la practica son:
- Github: gestionaremos el repositorio y los cambios del proyecto.
